# CICU Ventilation Lab

Mechanical ventilation simulator for pediatric cardiac ICU education, in three modes:

- **Teach** (`teach.html`): instructor-led, full control of ventilator and patient
- **Learn** (`learn.html`): ten self-paced modules
- **Check-off** (`check.html`): blinded APP competency cases with scoring

Each page is a single self-contained HTML file. Progress is saved in the viewer's browser only.

Independent approximation of a Servo-u–style ventilator for education only. Not a Getinge product or a medical device.
